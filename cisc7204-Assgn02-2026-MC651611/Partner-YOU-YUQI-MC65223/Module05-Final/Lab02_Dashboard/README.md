# Module 05 Final Lab 02

This project runs the Automobile Sales Statistics Dashboard.

Run:

```powershell
python -m pip install -r requirements.txt
python DV0101EN-Final-Assign-Part-2-Questions.py
```

Then open the local Dash URL printed in the terminal.

The data file is included as `historical_automobile_sales.csv`. The `screenshots` folder records the yearly, recession, and task views used in the forum post.
