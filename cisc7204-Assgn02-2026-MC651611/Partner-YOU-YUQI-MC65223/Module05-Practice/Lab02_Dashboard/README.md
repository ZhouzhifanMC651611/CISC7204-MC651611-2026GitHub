# Module 05 Practice Lab 02

This project runs the Australia Wildfire Dashboard.

Run:

```powershell
python -m pip install -r requirements.txt
python Dash_wildfire.py
```

Then open `http://127.0.0.1:8050`.

The data file is included as `Historical_Wildfires.csv`. The `screenshots` folder records the dashboard states used in the forum post.
